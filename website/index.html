FROM GATE TO FINAL

ATC that follows the flight,
not a scripted conversation.

Start offline, add only the services you want, and keep the rules deterministic.

01
VOICE & CONTROL

Talk naturally. Transmit like a pilot.

Hold a keyboard key or bind a button on your joystick, yoke, gamepad, or HOTAS. Accent-aware hints improve aviation terms without saving your raw microphone audio.

Hardware PTTVoice trainerTyped fallback
02
READBACKS

Corrections that name the actual mistake.

Runway, altitude, squawk, route, and frequency are checked item by item. Correct values stay correct instead of restarting the exchange.

03
GATE TO GATE

One session, every controller.

Delivery, ground, tower, departure, centre, and approach hand off according to the deterministic session state.

04
FLIGHT PLANS

Bring in your SimBrief route.

Enter a SimBrief user ID once and fetch the latest operational flight plan directly inside the app.

05
START OFFLINE

Useful before you add an account.

The mock simulator, typed radio, local parser, deterministic phraseology, and training guidance work without API keys or a network connection.

A CLEAR AUTHORITY BOUNDARY

Natural language.
Deterministic decisions.

A model can help understand what the pilot meant and make an approved instruction sound natural. It never decides where the aircraft is or what ATC may clear.

ASSIST
LOCAL-FIRST BY DESIGN

Your keys stay yours.

StormATC has no accounts and no telemetry. API keys are encrypted for your Windows user, network providers require explicit consent, and official provider hosts are pinned before credentials can be used.
